# SegedaFrontEndPro01112026

A simple Express.js REST API project.

## Description

This project is a Node.js application built with Express.js framework.

## Installation

```bash
npm install
```

## Usage

```bash
npm start
```

## Project Structure

- `index.js` - Main application entry point
- `models/` - Database models
  - `user.js` - User model
  - `quote.js` - Quote model

## Technologies

- Node.js
- Express.js
- MongoDB (via Mongoose)
